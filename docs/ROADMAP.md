# Product Roadmap & Future Architecture

## Phase 1 (Completed in Initial Release)
- [x] **Deterministic Progressive Overload Engine:** Standard double progression, dynamic double progression, linear strength, and bodyweight progression.
- [x] **Fatigue & Deload Protocols:** Stagnation radar (3-session rule), RIR 0 effort gating, and rust/acclimation adjustments (>14 days).
- [x] **Sub-Second Gym Floor Logging:** 1-tap set completion with ghost pre-fill and RIR selector.
- [x] **Active Rest Timer:** Floating countdown HUD with native Web Audio synthesis and mobile haptic vibration cues.
- [x] **Barbell Plate Calculator:** Interactive visual Olympic barbell plate stack solver for 20kg/45lb bars.
- [x] **Warm-Up Ramp Protocol:** Automated 4-tier neural potentiation warm-up ramp calculator.
- [x] **Performance Dashboard:** Weekly volume vs. 10–20 set science landmarks, progression velocity, PR tracking.
- [x] **Explainable Smart Coach:** Data-grounded diagnostics distinguishing observations, hypotheses, and actionable adjustments.
- [x] **Data Sovereignty:** 100% offline local-first storage, JSON backup export/import, CSV spreadsheet export.

---

## Phase 2 (Near-Term Enhancements)
- [ ] **Capacitor Mobile Wrapper:** Wrap application for 1-click native iOS (App Store) and Android (Google Play) distribution with background audio modes.
- [ ] **Wearable & Smartwatch Companion:** Apple Watch / Wear OS companion app for set checking and wrist rest timer vibrations.
- [ ] **Bar Velocity Video Integration:** Native camera tracking using MediaPipe Pose to measure barbell concentric velocity in meters/second for velocity-based training (VBT).
- [ ] **CRDT-based Peer-to-Peer Sync:** Encrypted multi-device sync across phone, tablet, and desktop without requiring a central login server (using Automerge or Yjs).

---

## Phase 3 (Advanced Analytics & Community)
- [ ] **Mesocycle Periodization Planner:** Plan 4-to-8 week blocks with automated volume ramp accumulation, peak week, and scheduled deloads.
- [ ] **Gym Equipment Profile Presets:** Save customized dumbbell racks (e.g. 2.5kg vs 5lb increments) and machine weight stacks per gym location.
- [ ] **Biomarker & Wearable Sleep Integration:** Connect Apple Health / Health Connect to correlate overnight HRV (Heart Rate Variability) and sleep duration with daily progression readiness.
